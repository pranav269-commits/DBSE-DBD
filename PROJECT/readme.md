# DINE — Smart QR-Based Restaurant Ordering System

Latest version: **DINE Premium OneClick Phone DB Fixed v3** (1 October 2026).

The complete project is in [DINE-Premium](./DINE-Premium).

- **Frontend:** React + Vite
- **Backend:** FastAPI + SQLAlchemy
- **Database:** MySQL; schema and seed SQL included
- **Features:** 12 table QR codes, phone ordering, kitchen dashboard, live status tracking, cashier and admin screens

## Run on Windows

Install Python 3.12, Node.js 20+ and MySQL Community Server 8.x. Open `DINE-Premium` and double-click `START_DINE.bat`. First setup asks for your MySQL root password.

See [setup instructions](./DINE-Premium/README.md), [one-click guide](./DINE-Premium/ONE_CLICK_WINDOWS.md) and [phone/QR access](./DINE-Premium/PHONE_QR_ACCESS.md).
